# Grow Me Organic Assignment

This is a React + TypeScript project built using Vite and PrimeReact.

## Live Demo
https://growmeorganic-tabledata.netlify.app

## Tech Stack
- React
- TypeScript
- Vite
- PrimeReact
- CSS

## Features
- Data table implementation
- Responsive UI
- Context API usage

## Setup Instructions

1. Clone the repository
```bash
git clone https://github.com/radhikapatidar9/GrowMeOrganic-Assignment.git
```

2. Install dependencies
```bash
npm install
```
3. Run the project
```bash
npm run dev
```
